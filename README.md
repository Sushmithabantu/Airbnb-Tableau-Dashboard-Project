# Airbnb Tableau Dashboard Project

##  Project Overview
This project is an interactive Airbnb Data Analysis Dashboard created using Tableau. The dashboard helps analyze Airbnb listings, pricing trends, availability, and customer-related insights through effective visualizations and data storytelling techniques.

The main objective of this project is to transform raw Airbnb data into meaningful business insights using interactive dashboards.

---

##  Dashboard Features
- Interactive Tableau Dashboard
- KPI Metrics and Summary Cards
- Price Trend Analysis
- Availability Analysis
- Customer and Listing Insights
- Filters and Drill-down Functionality
- Clean and User-friendly Visualizations

---

##  Tools & Technologies Used
- Tableau

- Data Analytics
- Data Visualization
